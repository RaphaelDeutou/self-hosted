# self-hosted

Exemple minimal de GitHub Action composite ("hello-world") déclenchée par un workflow, utilisé pour apprendre le fonctionnement des actions personnalisées et des runners self-hosted.

## Contenu

- `.github/hello-world/action.yaml` — définition de l'action composite
- `.github/workflows/say_hello.yaml` — workflow qui l'exécute

## Statut

Dépôt d'apprentissage / bac à sable autour de GitHub Actions, pas un projet applicatif.
